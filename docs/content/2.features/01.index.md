---
title: Features
description: Everything a widget can do beyond static layouts, with recordings from the real renderer.
---

Every feature works from the same JSON config on every platform; where a platform cannot
do something, [Core vs extended](/guide/tiers) says what it does instead.

::demo-video{src="island-demos" caption="Live activities in the desktop Dynamic Island (recorded from the built-in renderer)."}
::

::card-group
  :::card{title="Dynamic Island" icon="i-lucide-pill" to="/features/dynamic-island"}
  A live activity as a pill around the camera notch: iPhone, macOS, Windows, Linux.
  :::

  :::card{title="Live activities" icon="i-lucide-radio" to="/features/live-activities"}
  A running task outside the app: Lock Screen, ongoing notification, desktop island.
  :::

  :::card{title="Interactive widgets" icon="i-lucide-pointer" to="/features/interactive"}
  Buttons and links that reach your app, and taps that change the widget by themselves.
  :::

  :::card{title="Timelines and transitions" icon="i-lucide-calendar-clock" to="/features/timelines"}
  Prepared layouts for later times, switched without the app; animated changes.
  :::

  :::card{title="Remote data" icon="i-lucide-cloud-download" to="/features/remote-data"}
  Send only values from the app, or let the widget fetch JSON from a URL itself.
  :::

  :::card{title="Widget updater" icon="i-lucide-refresh-cw" to="/features/widget-updater"}
  Push fresh values on a timer: clocks, dashboards, counters.
  :::

  :::card{title="Instances" icon="i-lucide-copy" to="/features/instances"}
  One widget placed twice with its own settings and data.
  :::

  :::card{title="Conditions, lists and templates" icon="i-lucide-git-branch" to="/features/dynamic-content"}
  Show parts only when data matches, build lists from arrays, reuse parts, localize text.
  :::

  :::card{title="Images" icon="i-lucide-image" to="/features/images"}
  SF Symbols, base64 and URLs, clipped and sized the same everywhere.
  :::

  :::card{title="Desktop widgets" icon="i-lucide-app-window" to="/guide/setup/desktop"}
  Frameless widget windows: pinned to the desktop, click-through, remembered positions.
  :::
::
