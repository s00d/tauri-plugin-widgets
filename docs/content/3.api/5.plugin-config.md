---
title: Plugin config
---

Optional. Everything under `plugins.widgets` in `tauri.conf.json` has a default:

```json
{
  "plugins": {
    "widgets": {
      "appGroup": "group.com.example.myapp",
      "transport": "widgetContainer",
      "extensionBundleId": "com.example.myapp.widgetkit"
    }
  }
}
```

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `appGroup` | string | `group.<identifier>` | App Group / shared storage group. Also the default `group` for JS calls. |
| `transport` | `widgetContainer` \| `appGroup` \| `userDefaults` \| `auto` | macOS `widgetContainer`, iOS `appGroup` | Apple host write driver. iOS accepts `appGroup` only. See [Transport](/guide/transport). |
| `extensionBundleId` | string | `<identifier>.widgetkit` | macOS widget extension bundle id (`widgetContainer` path) |
| `restoreWindowsOnStart` | boolean | `false` | Desktop: reopen the widget windows that were open when the app last quit (positions are remembered per window). |
| `activitySurface` | `"island"` \| `"window"` \| `"notification"` | `"island"` | Desktop surface for live activities: `"island"` a Dynamic-Island pill at the top centre of the primary display (around the notch on notched Macs, expands on hover); `"window"` the small always-on-top window in the top-right corner; `"notification"` a system notification (Linux / Windows, cargo feature `notify`). |

Permissions: [Permissions](/api/permissions). Environment overrides: [Environment](/api/env).
