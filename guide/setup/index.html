Platform setup ​

Pick a surface. Desktop is the fastest feedback loop; native extensions take longer but ship on the home screen.

PlatformSurfaceRough timeGuide
DesktopFrameless webview~10 minDesktop · First widget
AndroidJetpack Glance AppWidget~30–60 minAndroid
iOSWidgetKit extension~1–2 h (Xcode)iOS
macOSWidgetKit .appex + tauri build~1–2 hmacOS
WindowsWidgets Board and/or desktop webview~1 hWindows
LinuxDesktop webview + X11 pin~30 minLinux

Before any Apple surface (including desktop webview on a Mac): run init-macos / init-ios (writes plugins.widgets) or npx tauri-widgets signing --apply. See Install.

Each setup page ends with When it fails. Symptom index: Troubleshooting.
